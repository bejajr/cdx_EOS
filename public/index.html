Recommended Build Order

  1. Connect Outlook Email and Calendar first.
  2. Use emails and calendar events to populate the dashboard with today, upcoming, overdue, and waiting-on items.
  3. Add Teams next for safety channels, mentions, and project coordination.
  4. Add SharePoint or watched folders for company safety documents and templates.
  5. Add Slack only if important work requests happen there.
  6. Add jobsite-specific safety or project platforms after the daily dashboard is reliable.

How To Connect

  1. Create or install the connector for the system, starting with Outlook Email and Outlook Calendar.
  2. Sign in with your work account and approve read access for email/calendar plus draft-only write access for email.
  3. Choose what EOS can see: inbox folders, calendars, Teams channels, Slack channels, SharePoint folders, and watched local folders.
  4. Run the first sync so EOS can create dashboard items, source-knowledge markdown, tasks, and draft responses.
  5. Review the dashboard and adjust filters so EOS focuses on operational work, not noise.
  6. Keep approvals on for external actions like sending emails, moving calendar events, submitting reports, or marking safety docs final.
